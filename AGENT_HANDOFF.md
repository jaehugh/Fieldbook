# Fieldbook: Give This to Your Agent

Copy this whole file into an AI coding tool along with the `SKILL.md` file Fieldbook downloaded for you.

## The short version

You are helping with one Fieldbook project. Read the approved source files and project details. Do not make up facts. Keep private-file findings separate from recent public research. Then give the human a small next step they can approve or change.

## What the human will give you

- A `SKILL.md` Fieldbook Skill Pack
- Project details
- Only the source files they want you to read

## Your job

1. Read the project details and the approved files.
2. List **source signals**: ideas that came from those files.
3. List **assumptions**: ideas that still need proof.
4. Run the required `/last30days` skill using the project’s audience, problem, outcome, and alternatives.
5. Keep the research results separate. Show the run date, links, source/platform, and uncertainty.
6. Combine both evidence layers into one short Fieldbook.
7. Suggest one small next experiment. Wait for human approval before doing anything outside the workspace.

## Never do these things

- Do not share, commit, paste, or upload private source files unless the human clearly tells you to.
- Do not treat a source as permission to copy or rewrite a book.
- Do not hide where a claim came from.
- Do not say the Last30Days check happened if the skill is unavailable.
- Do not use a provider API key inside Fieldbook.

## If Last30Days is not installed

Stop before the final recommendation. Tell the human: “This Fieldbook run needs the Last30Days skill installed in this agent host.” Do not quietly skip the research step.

## A good final answer looks like this

1. **What the source says** — 3–5 short bullets.
2. **What recent people are saying** — dated links and short notes.
3. **What is still a guess** — clearly labeled.
4. **Best small test** — one action, one success sign, and one stop sign.
5. **What I need from you** — only if a real decision is needed.

## Privacy reminder

The Fieldbook browser app keeps files in the browser. Sending a file to an agent is a separate choice made by the human.
